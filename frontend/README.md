# frontend (React)

취준생이 관심 직무를 선택하고, 그 직무에 맞춰 구조화된 뉴스 브리핑을 조회하는 화면.

## 폴더 구조

- `public/` — 정적 파일 (index.html, favicon 등)
- `src/api/` — 백엔드 API 호출 모듈 (axios/fetch 래퍼)
- `src/components/` — 재사용 UI 컴포넌트 (뉴스 카드, 직무 선택기 등)
- `src/pages/` — 라우트 단위 화면 (브리핑 목록, 직무 설정 등)
- `src/hooks/` — 커스텀 훅 (브리핑 데이터 fetching 등)

> 아직 구현 전 단계 — 폴더 구조만 준비된 상태.
